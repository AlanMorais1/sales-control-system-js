# 🚀 Sales Control System

Sistema de controle de vendas desenvolvido com JavaScript e Node.js.

## 🎯 Objetivo

Projeto criado para praticar:

* Lógica de programação
* Desenvolvimento back-end
* APIs REST
* Estruturação de sistemas
* Integração entre front-end e back-end

Além do aprendizado técnico, o sistema foi pensado para resolver problemas reais de negócio relacionados a:

* Controle de vendas
* Gestão comercial
* Cálculo de comissão
* Organização de resultados

---

## 🛠️ Tecnologias utilizadas

* JavaScript (ES6+)
* Node.js
* Express
* HTML5
* CSS3
* Git & GitHub

---

## ⚙️ Funcionalidades

✅ Cadastro de vendas
✅ Cálculo automático de comissão
✅ Listagem de vendas
✅ API REST com Node.js
✅ Estrutura separada entre frontend e backend

---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos como:

* Estruturação de APIs
* Manipulação de arrays e objetos
* Organização de código
* Comunicação entre front-end e back-end
* Versionamento com Git
